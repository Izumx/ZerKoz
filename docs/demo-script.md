# Сценарий демонстрации (≈ 3 минуты)

**Подготовка:** `python -m app.seed.generate --reset`, затем `python -m app.main`. Панель открыта на ноутбуке, бот на телефоне, экран телефона транслируется (например, scrcpy или AirPlay).

## 0:00–0:20 · Проблема
«Инспектор объезжает участки вручную и сверяет их с картой. Житель не знает статус своего заявления и не может быстро сообщить о свалке. ЖерКөз замыкает эту связь».

## 0:20–1:05 · Панель инспектора
1. Карта Тараза: зелёные, жёлтые и красные участки. Обратите внимание: красные заштрихованы, жёлтые обведены пунктиром. Статус читается даже без цвета.
2. Счётчик «Срок истёк: 3» → клик → список просроченных.
3. Открываем участок: кадастровый номер, назначение, площадь, фото инспектора, NDVI («низкая вегетация — возможное неиспользование»), история.
4. Переключаем подложку на спутник.

## 1:05–2:10 · Житель в Telegram (главный момент)
1. `/start` → Қазақша/Русский → меню кнопками.
2. «📄 Статус заявления» → `KZ-2026-042` → «Назначен выезд инспектора» с пояснением.
3. «📚 База знаний» → «Участок под ИЖС» → шаги, документы, сроки, ссылка на eGov.
4. «🚨 Народный контроль» → 📍 геолокация → фото → «свалка у дороги» → ✅ Отправить → «Сигнал SIG-00XX принят».
5. **На ноутбуке без перезагрузки:** всплывает уведомление с фото, маркер пульсирует, участок пожелтел, счётчик сигналов вырос.

> Если Telegram недоступен: кнопка «⚡ Демо: сигнал жителя» даёт тот же эффект.

## 2:10–2:40 · Инспектор реагирует
1. «Показать» → карточка сигнала → «Подтвердить нарушение» (тип: свалка).
2. **На телефоне** приходит уведомление: «⚠️ Нарушение подтверждено».
3. «Открыть участок» → контрольный срок +14 дней → «Начать устранение» → «Устранено». Житель получает «✅ Устранено».

## 2:40–3:00 · Масштабирование
Импорт GeoJSON из ЕГКН одной командой, NDVI готов к Sentinel-2, переход на PostGIS меняет один модуль, RU/KZ, экспорт реестра в Excel.
