# Сценарий демонстрации (≈ 3 минуты)

**Подготовка:** `python -m app.seed.generate --reset`, затем `python -m app.main`, или откройте облачную ссылку. Панель открыта на ноутбуке, бот на телефоне, экран телефона транслируется (например, scrcpy или AirPlay).

## 0:00–0:20 · Проблема
«Инспектор объезжает участки вручную и сверяет их с картой. Житель не знает статус своего заявления и не может быстро сообщить о свалке. ЖерКөз замыкает эту связь».

## 0:20–1:05 · Панель инспектора
1. Панель открывается сразу, без входа: карта Тараза. Красные участки заштрихованы, жёлтые обведены пунктиром: статус читается даже без цвета.
2. Счётчик «Срок истёк: 3» → клик → список просроченных.
3. Открываем просроченный участок: срок, этапы, фото, NDVI «низкая вегетация — возможное неиспользование», **🖨 Акт осмотра** → готовый документ A4.
4. Открываем участок `06-084-023-112`: **реальный NDVI со спутника Sentinel-2** (пометка «🛰 Sentinel-2 L2A»). Кнопка «Загрузить из Sentinel-2» подтягивает свежие снимки за несколько секунд.
5. Вкладка **Маршрут**: 9 точек в порядке объезда → «Google Карты».

## 1:05–2:05 · Житель в Telegram (главный момент)
1. `/start` → Қазақша/Русский.
2. `KZ-2026-042` → «Назначен выезд инспектора» → **🔔 Уведомлять об изменениях**.
3. «📚 База знаний» → «Участок под ИЖС» → кнопка на реальную услугу eGov.
4. «🚨 Народный контроль» → 📍 → фото → «свалка у дороги» → ✅ → «Сигнал принят».
5. **На ноутбуке без перезагрузки:** уведомление с фото, пульсирующий маркер, участок пожелтел. В карточке тип нарушения уже подставлен по описанию жителя.

> Если Telegram недоступен: кнопка «⚡ Демо: сигнал жителя» даёт тот же эффект.

## 2:05–2:40 · Инспектор реагирует
1. «Подтвердить нарушение» (тип уже подставлен) → **на телефоне**: «⚠️ Нарушение подтверждено».
2. Вкладка **Заявления** → KZ-2026-042 → «Одобрено» → **на телефоне** приходит уведомление о новом этапе.
3. Покажите SIG-0001 «👥 2»: два жителя сообщили об одной свалке, сообщения объединены, уведомления получат оба.

## 2:40–3:00 · Масштабирование
Sentinel-2 через Copernicus уже работает на сервере, импорт GeoJSON из ЕГКН одной командой, webhook и Redis для нагрузки, переход на PostGIS меняет один модуль, RU/KZ.
